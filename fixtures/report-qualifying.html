Stored XSS in the Acme Router web panel, firmware 2.4

In scope: the router web panel, firmware 2.4. This report demonstrates a reproducible security issue with steps to reproduce and its impact.

Affected version

Firmware 2.4, web panel build 2.4.117, reproduced on two factory-reset devices.

Steps to reproduce

  1. Open the panel, sign in, go to Settings > Device name.
  2. Save the payload <script>fetch('/session').then(...)</script>.
  3. Open Status > Overview. The script runs in the session of any viewer.

Impact

Session theft of any administrator viewing the overview page; full configuration control follows. Demonstrated end to end on a local device.
